# КС Авто 26

## Подключение тестовой базы

1. Создайте проект Supabase. В SQL Editor выполните `supabase/migrations/001_bookings.sql`.
2. В Authentication отключите самостоятельную регистрацию и добавьте пользователя с подтверждённой почтой. Скопируйте его UUID и выполните в SQL Editor:

   ```sql
   insert into public.booking_owners (user_id)
   values ('UUID пользователя'::uuid);
   ```

3. В `js/config.js` укажите URL проекта и публичный ключ Publishable. Секретный ключ сюда не добавляйте.
4. Откройте сайт по HTTP(S), отправьте тестовую заявку и войдите в `admin.html` под созданным пользователем. Проверьте телефон, услугу, дату, время и изменение статуса. Если убрать пользователя из `booking_owners`, его доступ к заявкам прекратится.
5. Для проверки используйте вымышленные данные. Пока база не настроена, форма показывает сообщение о недоступности и предлагает позвонить.

## Уведомления в Telegram

Заявки сохраняются и без уведомлений. Для Telegram сначала отзовите ранее опубликованный токен в BotFather. Затем включите расширение pg_net в Supabase, добавьте в Vault секреты `telegram_bot_token` и `telegram_chat_id` и выполните SQL из `supabase/optional/telegram.sql`. Получатель должен предварительно открыть чат с ботом и нажать «Старт».

При сохранении новой заявки бот получит задание отправить номер заявки. Телефон и имя доступны в кабинете. Доставка зависит от Telegram. Проверьте её отдельно тестовой заявкой.
